# Marca oficial Fut de Sexta

As imagens `logo-light.png` e `logo-dark.png` foram recortadas da
arte aprovada para o Fut de Sexta. Não são arquivos vetoriais editáveis.

Os ícones de aplicativo estão em `../icons/`:

- `fut-light-192.png` e `fut-light-512.png`: ícones padrão do PWA.
- `fut-light-maskable-512.png`: ícone com área segura para máscaras.
- `fut-dark-192.png` e `fut-dark-512.png`: ícones para interfaces escuras.
- `fut-dark-maskable-512.png`: variante maskable escura.
- `apple-touch-icon.png`: tela inicial do iOS.

O `manifest.webmanifest` aponta para as versões claras de instalação,
e o cabeçalho alterna automaticamente a versão conforme o tema real do app.
Para trocar ícones do manifest conforme o tema do sistema, é necessário
avaliar o suporte específico de cada navegador.

As imagens são recursos públicos da identidade visual. Não envie fotos
ou dados privados de usuários para esta pasta.
